# GitHub Discussions Guidance

Use GitHub Discussions to keep long-form, non-issue conversations organized.

## Suggested Discussion Categories

- **Ideas**: product and UX proposals
- **Q&A**: setup and usage help
- **Show and Tell**: resumes built with the tool (without personal sensitive data)
- **Announcements**: release highlights and roadmap notes

## Recommended Description

"Welcome to AI Resume Builder Discussions. Use this space for ideas, Q&A, and collaborative product conversations that are not actionable bugs."

## Moderation Guidance

- Keep conversations respectful and on-topic
- Redirect confirmed bugs/features to Issues using templates
- Avoid posting personal or sensitive resume information publicly
