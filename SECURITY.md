# Security Policy

## Supported Versions

The `main` branch is actively supported with security updates.

## Reporting a Vulnerability

If you discover a security issue, please do not open a public issue first.

1. Open a private vulnerability report through GitHub Security Advisories (preferred), or
2. Contact the maintainer directly via GitHub profile communication channels.

Please include:

- A clear description of the vulnerability
- Reproduction steps or proof of concept
- Potential impact assessment
- Suggested remediation (if known)

We will acknowledge reports as quickly as possible and work toward remediation.
